## 📋 О проекте

Веб-калькулятор для расчёта заказов теплоизоляционных цилиндров на основе входящих заявок.  
Заменяет ручной расчёт в Excel и позволяет менеджерам быстро получать точные данные по заказу.

**Данные встроены напрямую из файла поставщика** — калькулятор работает без сервера и интернета.

---

## ⚡ Возможности

| Функция | Описание |
|---|---|
| 🔢 Расчёт из погонных метров | Вводите длину трубопровода → получаете шт, коробки, вес |
| 📦 Расчёт из объёма м³ | Вводите м³ → получаете количество и погонные метры |
| 🔢 Расчёт из штук | Вводите количество цилиндров → получаете коробки и вес |
| 📋 Многопозиционный режим | Несколько позиций в одной заявке, итоговая сводка |
| 🏷️ 4 типа цилиндров | ISOL 80, 80-Ф, ISOL 100, 100-Ф |
| 📐 41 диаметр | От 18 до 1020 мм |
| 📏 9 толщин стенки | От 20 до 100 мм |

## 📊 Что рассчитывается

На выходе по каждой позиции заявки:

- ✅ **Количество цилиндров** (шт)
- ✅ **Количество коробок** (округление вверх)
- ✅ **Погонные метры** трубопровода
- ✅ **Объём** теплоизоляции (м³)
- ✅ **Общий вес** заказа (кг)
- ✅ **Транспортный объём** упакованных коробок (м³)

## ⚠️ Известные ограничения
